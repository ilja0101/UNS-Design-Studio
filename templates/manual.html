User Manual

UNS Design Studio

Operator guide

Build, simulate, inspect, and publish a virtual UNS.

UNS Design Studio is a local industrial simulator for designing a Unified Namespace tree, generating OPC UA data, injecting anomalies, and bridging live values to MQTT or NATS.

Open Dashboard Design UNS Live View

1. Start the simulator

  1. Open the Dashboard.
  2. Press Start Server to launch the OPC UA server.
  3. Wait until Server and OPC UA both show connected.
  4. Use the red emergency plant switch to start or stop all plants.

Plants cannot be started while the OPC UA server is stopped; the switch greys out and shows a warning.

2. Understand the Dashboard

  • Each plant card shows recipe, OEE, power, produced tons, inbound trucks, and run state.
  • Running factories light up and emit smoke.
  • Use Control to set a single plant running/stopped or change recipe.
  • Use Anomaly to override numeric simulation tags for a configurable duration.

3. Design the UNS

  • Open UNS Designer to edit enterprise, business units, sites, areas, work centers, work units, devices, and tags.
  • Site names remain bare in state keys, while OPC UA site nodes use Factory-prefixed names internally.
  • Save changes to rewrite the live UNS configuration, restart the simulator components, and sync simulation state.

4. Configure recipes and tags

  • Add recipes at site level and select active recipes from the Dashboard plant control modal.
  • Add simulation profiles to tags to make them discoverable for dashboard metrics and live publishing.
  • Use Payload Schemas to document or shape payload expectations for downstream systems.

5. Bridge data to MQTT or NATS

  1. Open Broker Config from the left menu.
  2. Select MQTT or NATS, configure host, port, credentials, topic prefix, and interval.
  3. Start the bridge from the Dashboard bridge bar.
  4. Monitor OPC, broker status, publish rate, and published message count.

6. Live UNS View

  • Use Live UNS View to inspect live broker traffic and topic structure.
  • Start the bridge before expecting live MQTT or NATS updates.
  • Use the topic tree to verify downstream namespace shape.

Troubleshooting

Plants will not start

Start the OPC UA server first and wait for OPC UA connected status. Then use the emergency plant switch.

No broker messages

Check Broker Config, start the bridge, and confirm the broker status says Connected.

Metrics show dashes

Confirm the plant is running, OPC is connected, and tags have simulation profiles for dashboard discovery.

Designer changes not visible

Save the UNS Designer. The dashboard reloads when the enterprise structure changes.
